# gprai.github.io — Personal Website

Static site for [gprai.github.io](https://gprai.github.io), generated by a single Python script.

## Structure

```
build.py                  ← site generator (edit this to update content)
.github/workflows/
  deploy.yml              ← auto-builds & deploys on push to main
docs/                     ← generated output (served by GitHub Pages)
  index.html
  stack.html
  projects.html
  services.html
  contact.html
  projects/
    microservices-eks-terraform.html
    aws-platform.html
```

## Local development

```bash
python build.py           # regenerates docs/
# then open docs/index.html in your browser
```

No dependencies — pure Python stdlib.

## Deployment

Every push to `main` triggers the GitHub Actions workflow which:
1. Runs `python build.py`
2. Pushes `docs/` to the `gh-pages` branch

### GitHub Pages settings

In **Settings → Pages**:
- **Source**: `Deploy from a branch`
- **Branch**: `gh-pages` / `/ (root)`

That's it — the workflow handles the rest.

## Updating content

All site data (certifications, projects, services, stack) lives at the top of `build.py`
in plain Python dicts/lists. Edit there and push — the site rebuilds automatically.
